Bounty Hunter Config Window Styles
==================================

The bright Town Hall style is installed by default.

To use another style:

1. Open the folder of the desired style.
2. Copy bounty_cfg.zip into the mod's Data folder.
3. Replace the existing bounty_cfg.zip when prompted.
4. Restart the game.

Only the appearance of the configuration window is changed. The settings,
translations and saved configuration remain unchanged.

Keep a copy of the default style if you modify the archives manually.
